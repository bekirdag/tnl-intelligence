# TNL Intelligence for Activepieces

This directory contains the standalone public Activepieces community piece.

- Package: `@theneuralledger/piece-tnl-intelligence`
- Runtime source: `piece-tnl-intelligence/src`
- Tests: `piece-tnl-intelligence/test`
- Build: `npm run build`
- Qualification: `npm test && npm run pack:check`

The package uses only fixed TNL production endpoints and exposes six read-only
actions.
